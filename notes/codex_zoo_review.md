# Codex review of THE ZOO (abstract-interpretation generalization)

**Bottom line:** zoo is directionally right, but NARROW the claim to "**checked neural abstract-STATE organs**,"
not "general abstract interpretation" (classical AI / interval-CP / CLP-SMT / DeepPoly / diff-opt / NAR own that
territory). Our novelty is THE WEAVE: LM compiles a per-instance abstract program → learned recurrent organ
proposes reductions → γ writes structured state back into generation → causal controls prove recruitment.

## Corrections (important)
1. **OVERCLAIM: "every cell sound at the output-check" is wrong.** Output-verification makes ACCEPTED ANSWERS
   sound, NOT intermediate organ states (our own OOD-soundness break proves it). → organs are **proposal engines**;
   **composition needs CERTIFIED reductions** (one unsound reduction poisons the next organ before the final check).
2. **The zoo only holds if every domain has explicit semantics**: α, concretization γ, top/bottom, meet/reduction,
   verifier/certificate, abstain. Else "domain × operation" = a taxonomy of vibes.

## Interval organ → CERTIFIED CONTRACTORS (not neural-decides-bounds)
old box + typed constraints → NEURAL proposes contraction/contractor/var-order → CERTIFIED guard (interval/FBBT/LP)
proves it preserves ALL solutions → meet, else ABSTAIN. Pitfalls: anti-extensive ≠ sound; gradient endpoints
untrustworthy (roundoff/NaN/÷0/open-closed → silent false-elim); no cheap exact-dedₚ over reals (targets = classical
interval-CP / LP / SMT + known-exact synthetics); widening NOT in the soundness path early; intervals alone weak
for integers/parity/modular → need REDUCED PRODUCTS (intervals × sign × parity/congruence × octagons).

## Affine wall — only HALF beaten
Grade-3/level-2 fixes the LOCAL representation of ONE ternary affine constraint. But arbitrary XOR *systems* are an
algorithmic/WIDTH problem needing Gaussian-elimination / row-space state, not "triples + depth" at fixed budget.
→ Run rank/pathwidth-swept XOR-SAT before claiming the wall is beaten. (May need a "linear-algebra organ.")

## Routing/composition — DON'T expect pure CPT to discover it
Single-organ recruitment ≠ multi-organ typed dispatch. Soundest path: (1) typed protocol (state/γ/abstain/cert/cost),
(2) verifier-selected PORTFOLIO first, (3) log oracle routes, (4) train router to imitate→optimize, (5) learned
routing only over CERTIFIED outputs + top-k fallback + verifier-selection. Composition = REDUCED PRODUCTS (each
reducer with its own soundness rule), not dense fusion.
